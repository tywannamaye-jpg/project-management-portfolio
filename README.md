# Tywanna Maye | Project Delivery & Customer Success Portfolio

A static, mobile-friendly portfolio designed for free hosting on GitHub Pages.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `project-management-portfolio` under your GitHub username. If that repository already exists, open it instead.
2. Upload `index.html`, `style.css`, and `.nojekyll` to the repository root, and commit the changes. You can also upload this README.
3. Open repository **Settings > Pages**.
4. Set **Build and deployment > Source** to **Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, then **Save**.
6. After deployment, use the **Visit site** link in Settings > Pages to confirm the correct URL. GitHub says publishing can take up to 10 minutes.

Your published portfolio URL is:
https://tywannamaye-jpg.github.io/project-management-portfolio/

Do not add this URL to job applications until it loads successfully.

## Editing

Edit `index.html` to change content and links. Edit `style.css` for design. Commit updates to `main` to republish.

## Privacy

Do not upload private analytics, internal client files, credentials, or confidential Trello board content. The United MSD dashboard is summarized as a case study rather than exposed publicly.
